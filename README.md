# chappellRoan
Chappell Roan inspired R color pallettes (chappallettes)!  
Your favorite aRtist's favorite R kit to make super graphic ultra modern ggplots like mine 💅

## Download in R:
```r library(devtools)   
install_github("cdfine/chappellRoan")     
library(chappellRoan)
```

## Usage examples
Within ggplot:    
scale_fill_chappallettes(palette='Pink Pony Club')     
scale_color_chappallettes(palette='Pink Pony Club')  
chappallettes() lists all of the different color palette options.

## Examples of ggplot graphs with these palettes

```r
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, colour = Species)) +
  geom_point(size = 3) +
  scale_color_chappallettes(palette = "Good Luck Babe") +
  theme_minimal()
```
<img width="972" height="642" alt="goodluckbabeflowers" src="https://github.com/user-attachments/assets/2619fb03-3a1c-40e1-9fd4-7f57e7472911" />

```r
ggplot(diamonds, aes(x = cut, fill = cut)) +
geom_bar() +
scale_fill_chappallettes(palette = "Pink Pony Club") +
theme_minimal()
```
<img width="1058" height="642" alt="PinkPonyClubGraph" src="https://github.com/user-attachments/assets/3940fb65-2a5c-4d9c-aa2c-a8df01eb2648" />

```r
ggplot(volcano_df, aes(x = x, y = y, fill = elevation)) +
  geom_tile() +
  scale_fill_chappallettes(
    palette = "Love Me Anyway",
    discrete = FALSE
  ) +
  theme_minimal() +
  theme(
    axis.text = element_blank(),
    axis.ticks = element_blank()
  )
```
