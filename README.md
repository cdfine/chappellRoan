# chappellRoan
Chappell Roan inspired R color pallettes (chappallettes)!
Your favorite aRtist's favorite R kit to make super graphic ultra modern graphs like mine
Make your ggplots 

## Download in R:
library(devtools)   
install_github("cdfine/chappellRoan")     
library(chappellRoan)

## Usage examples
Within ggplot:    
scale_fill_chappallettes(palette='Pink Pony Club')     
scale_color_chappallettes(palette='Pink Pony Club')
chappallettes() will list all of the different color palette options
